## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的分区大小差异越来越大，大的该拆、小的该合，但迁移过程中不能停止读写。请从零实现一个分区自动分裂与合并组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持按分区大小或访问量判定需要分裂与合并的分区，阈值可配置；2) 支持分裂：把一个分区按键范围拆成两个，拆分期间读写要能继续且路由层同时识别旧分区与新分区；3) 支持合并：相邻小区合并为一个，合并期间不得丢失任一分区数据；4) 支持原子切换：拆分或合并完成后一次性切换路由并回收旧分区，切换前后查询结果一致；5) 支持失败回滚：迁移中途失败要能回到操作前状态，不影响其它分区；6) 支持冷却：同一分区短时间内不重复分裂或合并，避免抖动；7) 提供统计：分区数、分裂次数、合并次数、迁移中的数据量与回滚次数；8) 测试覆盖判定规则、分裂与合并、迁移中读写、原子切换、失败回滚与冷却；`mvn -q verify` 一条命令跑通。
